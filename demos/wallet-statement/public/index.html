What this check establishes

The verifier independently decodes Ethereum’s Transfer events, checks block references and time boundaries, preserves repeated events, and recalculates amounts with exact integers. It also searches blocks absent from the citations to detect omissions.

Saved replay checks consistency with the archived Ethereum responses. Live verification trusts the selected Ethereum service to return correct, complete records; it does not validate Ethereum consensus. Run the downloaded verifier against your own node to choose your source of trust.

Scope, timing and source downloads

The report uses an active Ethereum contract address, not the connected payer’s wallet. Only USDC is compared. Nansen pages are fetched completely. Testril reads may reuse data already prepared by someone else.

Fresh-run query time includes payment negotiation and retrieval; wallet approval, Testril preparation and provenance are shown separately. Provider calls run sequentially to avoid overlapping approval prompts. The sample’s automated wallet timing does not represent a visitor approving each purchase.

Payment confirmations come from provider receipts. Deposits are separate from service charges, and a deposit transaction is not a second query fee. Unconfirmed outcomes stop the run and are never automatically resubmitted. Download an interrupted attempt before reviewing its payment status.
